# ACG アニメ速覧ガイド

一个面向动漫 / ACG 爱好者的可视化资料站，支持：

- 大规模作品库检索与分页浏览
- 题材、年代、来源、评分、排序等多维筛选
- 系列追番顺序参考
- 角色人气榜与聚类筛选
- 正版观看入口跳转
- 本季新番与公开资料检索

## 本地预览

直接在项目目录启动一个静态服务器即可，例如：

```bash
python3 -m http.server 4180
```

打开：

`http://localhost:4180/index.html`

## 项目结构

- `index.html`：页面结构
- `styles.css`：页面样式
- `app.js`：前端逻辑与本地精选数据
- `anime-dataset.js`：扩容后的公开作品库数据
- `scripts/fetch-anime-dataset.mjs`：作品库抓取与生成脚本
- `assets/`：站点资源

## 数据说明

- 站内扩容作品库基于 Jikan 公共接口生成
- 页面中的正版观看入口以各平台实时搜索结果为准
- 角色榜为站内整理结果，并附日本站点参考入口
